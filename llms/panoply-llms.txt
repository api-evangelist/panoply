# Panoply

> Panoply is a managed cloud data warehouse and ELT (Extract, Load, Transform) platform that centralizes data from 100+ sources into a BigQuery- or Redshift-backed warehouse. It pairs pre-built SaaS connectors and a customizable Flex Connector with a SQL workbench, code-free Query Builder, and in-platform dashboards, targeting startups and data teams that want analytics-ready data without managing infrastructure. Panoply is a SQream company.

## Integration surface
- [Flex Connector](https://panoply-documentation.document360.io/docs/): Customizable API connector (authorization, variables, pagination, access-token refresh, async API support) for ingesting arbitrary REST APIs into Panoply
- Note: Panoply does not publish a first-party public REST management API or OpenAPI spec; its programmable surface is the Flex Connector for consuming external APIs.
